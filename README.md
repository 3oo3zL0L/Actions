# Droplet

Thomas's personal work cockpit: one focus list across Outlook, Teams, Jira and Confluence, prioritized by Claude, where every item ends in an action that runs only after an explicit click.

- `droplet/`: the app, a claude.ai Artifact in plain HTML/CSS/JS, with its Playwright tests and publishing notes.
- `docs/droplet/`: the product brief, the priority rules and the approved designs.

The earlier Rails app ("Actielijst") was removed. It is still in the git history.
